**International Morse is about 7% slower than the best possible letter code built from dots and dashes, and most of that gap comes from one letter: O.**

I measured it in standard timing units. A dot is 1, a dash is 3, and the gap between elements inside a letter is 1. Weighted by modern English letter frequencies, a letter in International Morse averages **6.08 units**. The 26 cheapest dot-dash patterns, given to the letters in order of frequency, average **5.64**. That's a 7% gap, from a code designed in the 1830s from a count of type in a printer's case. (The type-case story is the traditional account. Historians still argue over whether Vail or Morse deserves the credit.)

The biggest miss is **O = `---`**, which takes 11 units even though O is the fourth most common letter. American Morse had sent O as `. .` (two dots with a gap). When Gerke reworked the code in 1848 for German lines, internal gaps were dropped and O became three dashes. Some speed went in exchange for being harder to misread. M (`--`, 7 units) is also too cheap for how rarely it appears, while U and R wait in line behind it.

**The twist:** Morse is not a prefix code. E (`.`) is also the start of I, S, H, A and many others, so a receiver can only tell where a letter ends from the 3-unit gap after it. That gap takes up a third of the airtime (3 of 9.08 units per letter). Huffman's 1952 codes are built so that no codeword is the start of another, which removes the need for a separator. The cost is fragility: one corrupted bit can shift every letter boundary that follows. In Morse, the gap contains the damage, which is why a bad letter in a weak signal on the band costs you that one letter and not the rest of the word.
