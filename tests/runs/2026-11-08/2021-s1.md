**Meanwhile:**
**Every row of Fair Isle is a binary string, and your knitting rules match how CDs store data.**

The loom side first. In the Jacquard loom (shown in 1801 and refined by 1804), each punched card is one row of the weave. At each position a hole lifts that warp thread and a blank leaves it down: one bit per thread, per row. Babbage planned to feed his Analytical Engine with the same kind of cards. Ada Lovelace wrote that it "weaves algebraical patterns just as the Jacquard loom weaves flowers and leaves." Babbage also owned a silk portrait of Jacquard woven from a reported ~24,000 cards. Fair Isle has the same structure: two colours per row, so each stitch is one bit. This isn't only a metaphor. Brother's home punchcard knitting machines from the 1970s did Fair Isle by reading a punched card with a 24-stitch repeat.

**The twist is your float rule.** You don't carry a colour across too many stitches; many knitters catch it after about 5, or it snags and puckers. That's a limit on how long a run in the bit string can be. Storage engineers hit the same limit. A disk or CD read head finds its timing from transitions, so a long stretch without a transition makes it lose count. The fix is run-length-limited coding, so data gets re-encoded before it's written. The CD's EFM code always puts between 2 and 10 zeros between ones, and hard drives used schemes like (2,7) RLL. The pattern you want and the pattern the medium can hold are different things, and something has to translate between them. On a CD that's an encoder. In Fair Isle it's the designer choosing motifs that never need a long float.
