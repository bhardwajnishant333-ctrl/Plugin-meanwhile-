**Your app may already have a Kotlin `String` field holding `null`, and the compiler can't see it.**

Gson doesn't call Kotlin constructors. If a class has no no-arg constructor, Gson creates the object with `sun.misc.Unsafe.allocateInstance`, which allocates memory and runs no constructor code. Then it sets each field directly by reflection.

What that skips:
- **Default values.** In `data class User(val name: String, val premium: Boolean = false)`, the default lives in the constructor, and the constructor never runs. A missing `premium` is just the JVM's zero value. That happens to be `false` here, so you'd never notice. A `List` defaults to `emptyList()` the same way, so a missing one comes back as `null`.
- **Null checks.** Kotlin's null checks are generated into constructors and function parameters. If the JSON has no `name`, Gson leaves the field `null`, and the crash comes later when something calls `.length`, far from where the JSON was parsed.
- **`init` blocks.** These never run either.

One exception: if every constructor parameter has a default, Kotlin generates a no-arg constructor. Gson calls that one, so the defaults do apply.

kotlinx.serialization generates its parsing code at compile time and goes through Kotlin's own rules. A missing field that has no default throws `MissingFieldException` right when the JSON is parsed.

**The twist:** after the migration, tests may start failing on JSON that "always worked." Some of those failures aren't new bugs. They're old ones Gson was hiding. Before you revert anything, check whether the server ever sent the missing field at all.

**The marathon is 42.195 km because of where the 1908 London Olympics put the royal box.**

Early Olympic marathons were just "about 40 km." Athens in 1896 was roughly 40 km, and the next few Games each ran a slightly different distance on a course that suited them. In 1908 London started the race at Windsor Castle. The usual story is that this let the royal children watch from the nursery, but that detail is folklore and I can't confirm it. The finish line was placed in front of the royal box inside the White City stadium. That made the total 26 miles and 385 yards, and the 385 yards was the stretch inside the stadium.

That stretch is also where the race became famous. Italy's Dorando Pietri entered the stadium first, turned the wrong way and collapsed several times. Officials helped him over the line, and he was disqualified for it. The American Johnny Hayes got the gold. Queen Alexandra gave Pietri a gilded cup the next day, and he became more famous than the winner.

The distance still wasn't fixed after that. Stockholm in 1912 and Antwerp in 1920 used different lengths again. In 1921 the IAAF, now World Athletics, adopted 42.195 km as the official distance. It's generally said they picked London's number because that race was the one everyone remembered.

**The twist:** a round 40 km was the natural standard, and the sport ended up with a number set by one event's seating plan, made famous by a man who didn't officially finish. Your hardest 385 yards come from that. The same thing happens in software when a default chosen for one convenient case becomes everyone's contract, much like Gson's.
