**Meanwhile:**
gRPC never sends a deadline as a clock time. It sends how much time is left, and every hop resets that clock when the request reaches it.

**How it works:** On the wire, a deadline is the HTTP/2 header `grpc-timeout`. The value is at most 8 digits plus a unit letter (H, M, S, m, u, n), so `250m` means 250 milliseconds remain. It's relative because two machines can't agree on the time. If server clocks drift by 300 ms, an absolute deadline would be wrong by 300 ms at every hop: some calls would fail at once and others would run long. With a relative value, each receiver works out its own deadline as "my clock now + 250 ms." When a handler passes its incoming context or deadline into its own outbound calls (Go's `ctx`, Java's `Context`), the remaining time carries down the chain on its own.

**The twist, part one:** Time spent on the network is never subtracted. The receiver starts counting when it reads the header, not when the sender sent it. Each hop quietly gains its network delay, so a deep call chain believes it has a little more time than the original caller is willing to wait. It's small per hop, but it means the edge can give up while the work underneath is still running.

**The twist, part two:** By default gRPC sets no deadline at all, and a call can wait forever. Deadline propagation only works if a request starts with one and every hop passes it on. One handler that starts a fresh context (`context.Background()` in Go, a new Context in Java) breaks the chain. Everything below it then becomes the "bird that can't turn back," still spending fat for a caller that left long ago.

Almost every injectable drug and vaccine sold in the US has been safety-tested with blood from a 450-million-year-old animal. That same animal's eggs are what a threatened shorebird schedules its migration around.

**How it works:** The rufa red knot flies roughly 15,000 km each way between Tierra del Fuego and the Canadian Arctic. The crabs' blood is blue because it carries oxygen with copper (hemocyanin) instead of iron. Their blood cells clot when they touch bacterial endotoxin. Frederik Bang and Jack Levin worked this out in the 1950s and 60s, and the extract (Limulus amebocyte lysate, LAL) became the standard endotoxin test after FDA approval in the 1970s.
