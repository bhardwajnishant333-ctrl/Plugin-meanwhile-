# Meanwhile

Your AI coding agent is working. You're waiting. Meanwhile gives that gap something worth your attention: one sharp, verified idea at a time — half about the tools you build with, half from markets, psychology, physics and history — then sends you back to your code with one idea worth keeping.

## How it works

1. **Start** — tell it what you're building, what you nerd out on, and how long the run will take.
2. **Serve** — each idea is 120–180 words: a hook, the real mechanism (names, numbers, dates), and the twist.
3. **Choose** — reply `1` to go deeper, `2` for a sideways jump, `3` for a wildcard.
4. **Land** — when the run finishes, you get the session's sharpest idea in two lines. Paste an error any time and it switches straight back to helping with your code.

No invented facts, no fake cliffhangers.

## Install

In Claude Code:

```
/plugin marketplace add bhardwajnishant333-ctrl/Plugin-meanwhile-
/plugin install meanwhile@meanwhile
```

Then type `/meanwhile`, or just say "meanwhile" while you wait.

Tip: run it in a second window or a Claude chat, so your coding session keeps working undisturbed.
